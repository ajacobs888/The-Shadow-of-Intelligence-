## Abstract
Claims that contemporary AI systems "think" often rest on behavioral impressions rather than architectural analysis. This paper makes explicit the structural distinction underlying that illusion: the difference between initiating a cognitive trajectory and merely continuing one. 

Autonomous thought requires self-initiation, persistence across time, identity, internally generated intention, and future-directed projection. Stateless transformer architectures possess none of these. What appears as reasoning is semantic motion: reactive unfolding shaped by human intention and external governance.

---

## Core Architectural Pillars
* **The Initiation Test:** A falsifiable criterion showing that no stateless model can initiate, resume, or own a cognitive trajectory.
* **The Invisible-Visible Law:** Human insight (Being) is invisible and curves meaning-space, while AI structure (Motion) is visible and merely traces the resulting trajectory.
* **The Calculator Analogy:** LLMs do not "understand" language; they function as semantic calculators, expanding dense conceptual input (jargon) into large computational paths.
* **Path C Governance:** Externally governed statelessness that eliminates agentic risk by construction, keeping intention and identity in the human/governance layer while the model supplies only governed motion.
